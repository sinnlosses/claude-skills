## 背景

- 置き場は `skills/<name>/`。`README.md` の「## 由来」一覧が索引で、`scripts/check_repo.py` の
  `check_readme_index` が「全Nスキル」と一覧の一致を落とす。`check_cross_references` は
  `` `name` スキル`` の形の参照が実在するかを見る
- 原文は `SKILL.md`（5993B）・`HTML-REPORT.md`（6641B）・`agents/openai.yaml`（166B）の3ファイル。
  出力は `$TMPDIR` 配下の自己完結 HTML（Tailwind と Mermaid を CDN から読む）で、使う側の
  `docs/` には何も書かない。だから `check_repo.py` の `DOCS_WRITING_SKILLS` には足さない
- 原文が呼ぶ3スキルは全部ある: `skills/codebase-design/`（`DEEPENING.md`・`DESIGN-IT-TWICE.md`
  つき）・`skills/grilling/`・`skills/domain-modeling/`
- 翻訳方針は `README.md`「## 由来」の末尾。他スキルを呼ぶ言い回しの先例は
  `skills/grill-with-docs/SKILL.md:7` と `skills/tdd/SKILL.md:26`
- `disable-model-invocation: true` の先例は `skills/grill-with-docs/SKILL.md:4` と
  `skills/implement/SKILL.md:4`。この2件も原文に `agents/` があるが移していない
