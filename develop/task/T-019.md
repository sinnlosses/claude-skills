## 目的

ドキュメント系のスキルが `docs/` の下の決まった名前を前提にしているのをやめ、置き場が違う
プロジェクトでも使えるようにする。既定値はいまと同じにして、既存の5リポジトリの挙動は変えない。

## 完了条件

- `skills/maintenance-docs/scripts/check_docs.py` が `--docs-dir`（既定 `docs`）と
  `--index`（既定 `README.md`）を受け、`docs/` と `docs/README.md` の直書きがそれ経由になっている
- `skills/domain-modeling/SKILL.md` に、`CONTEXT.md` と `docs/adr/` について
  「ユーザーが場所を指定したらそれに従う」に相当する1文がある
- 既定値のまま `python3 skills/maintenance-docs/scripts/check_docs.py .` を打った結果が、
  引数を足す前と同じ
- `./check.sh` が通る

## 背景

- `check_docs.py` は `docs/`・索引 `docs/README.md`・`docs/adr/`・`docs/research/`・`docs/history/`・
  `docs/history/maintenance/`・`README.md`・`CLAUDE.md` を合わせて40箇所以上で前提にしている。
  主なもの: `:101` `os.walk(os.path.join(root, "docs"))`、`:116` `for f in ("README.md", "CLAUDE.md")`、
  `:124` `read(os.path.join(root, "docs", "README.md"))`、`:34` `HISTORY_DIR = "history"`、
  `:37` `INDEX_EXEMPT = ("README.md",)`、`:201` `DOCS_PATH` の正規表現
- 引数の口はすでにある: `:250` `root`（既定 `.`）と `:251` `--skills-dir`。同じ形で足せる
- 逃げ道の有無がスキル間でバラついている。`skills/research/SKILL.md:12` と
  `skills/architecture-proposal/SKILL.md:149` には「ユーザーが場所を指定したらそれに従う」があるが、
  **`skills/domain-modeling/SKILL.md` には無い**（`CONTEXT.md` と `docs/adr/` が固定）

## 注意

- `docs/history/` を「どの検査の対象にもしない」扱い（`check_docs.py:34` 近くのコメント）は変えない
- `CLAUDE.md` の位置づけは T-020（設定ファイルを `AGENTS.md` → `CLAUDE.md` の順で探す）で動くので、
  このタスクでは `CLAUDE.md` の探索順に手を入れない。`--docs-dir` と `--index` だけにする
