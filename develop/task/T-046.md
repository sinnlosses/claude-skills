## 目的・背景
利用者の指示（2026-10-07）: スキルは tsukumo に依存しない（tsukumo 側も特定のスキルに依存しないと決めた）。スキルの文面が tsukumo の画面・ツールを前提にしている箇所を外す。

いまの主ブランチで tsukumo を前提にしている箇所（`grep -rn -i tsukumo skills agents` で見た）:
- `skills/retrospect/SKILL.md` の「1件だけ振り返る」手順2の材料の表、行「時間の偏り」の見る場所に「（あれば tsukumo の最終レポートの「段ごとの時間」）」。段ごとの時間は T-044 で `tw metrics --stages`（台帳の flow の記録）から取れるようになった
- `skills/next-task/SKILL.md` の「完了報告のフォーマット」5（`OVER` のときの1行に「tsukumo の中なら『文脈を空にして続ける』」）と、「`/loop` の続行判断」の `context_size.py` の表の `OVER` の行（`mcp__tsukumo__` で始まる MCP ツールを探し、tsukumo が `/clear` してから送り直す、と書く）

依存ではないので触らないもの: `skills/architecture-proposal/evals/evals.json` の eval の題材（リポジトリ名としての tsukumo）、`skills/list-tasks/SKILL.md` の出力例の行（例のデータ）、`token-usage-diet` スキル（tsukumo の記録を集計すること自体がスキルの目的）。

## やること
### 1. 振り返りの時間の材料を flow の記録にする
`skills/retrospect/SKILL.md` の「1件だけ振り返る」手順2の表、行「時間の偏り」の見る場所を「`長く待った呼び出し`・`tw metrics --stages --days 1` のこのタスクの段（`STAGE` の行）」の形にし、tsukumo の最終レポートの記述を消す。当たりの目安の「1つの段が全体の半分以上」はそのまま使える。
### 2. `/next-task` の続行判断から tsukumo の名指しを外す
`skills/next-task/SKILL.md` の「完了報告のフォーマット」5の「tsukumo の中なら『文脈を空にして続ける』」を「文脈を空にして送り直すツールで続けるなら『文脈を空にして続ける』」の形に、「`/loop` の続行判断」の表の `OVER` の行を「ツール一覧に、文脈を空にして依頼を送り直すツールがあれば…（そのツールが文脈を空にしてから送り直す）。無ければ…（文脈は Claude Code の自動の要約に任せる）」の形に直す。最後に `grep -rn -i tsukumo skills agents` を打ち、上の「触らないもの」以外に残っていないことを確かめてから `tw verify` を通す。
