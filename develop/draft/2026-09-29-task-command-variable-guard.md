# task.py を変数経由で呼んだ空振りを仕組みで防ぐ（振り返り: tsukumo の GH-97）

- 札: 黄 道具（5回目）
- 根拠: GH-97 の委譲先が `T="python3 …/task.py"` の変数経由で task を呼び、zsh が語分割せず「no such file」で落ちた（打ち直して通った）。9/24 の T-537 に続く2回目で、そのときは `;` でつないだ `git commit` だけが走り、`todo` のままのコミットができた。委譲の依頼文には「変数に入れず毎回そのまま打つ」と書いてあったが、防げていない
- 出し先: 仕組みで塞ぐ。`task` を PATH の通った1語のコマンド（`task-workflow` の `install.sh` が張るラッパー）にして、変数に入れる理由を無くす。あわせて `/next-task` の依頼文の `task` の略記をそのコマンド名に置き換える
