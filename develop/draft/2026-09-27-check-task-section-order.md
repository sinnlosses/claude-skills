# タスクファイルの節の並びを `task` に検査させる（振り返り: T-028）

- 根拠: T-028 の委譲先は `## やること` を `## 完了条件` の直後に置いた（正典「タスクファイル」の並びは
  目的 → 完了条件 → 背景 → 決まっていること → 解くべき論点 → やること → 注意）。委譲文とスキルの手順5に
  どちらも「置く位置は `## 注意` の前」と書いてあるのに外したので、文章で言うだけでは防げない。
  `task status --check` は並びを見ないため `OK` のまま通り、受け入れでメインが手で並べ替えた
  （そのとき本文中の `## 注意` を拾う置換で本文を割り、直しに2手かかった）
- 出し先: `skills/task-workflow/scripts/taskfile.py` に節の並びの検査を足し、`task done` が
  順番どおりでなければ `INVALID`（終了コード3）で止めるタスク。`task status --check` でも見る。
  並べ替えまで自動でやるかは論点（`done` は `## 結果` を書き足す口なので、そこで直せる余地がある）
